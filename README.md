# XAU Trading Desk — Android Update Channel

Official update channel for the standalone XAU Trading Desk Android app.

- `latest.json` is the signed-release manifest read by the app.
- APK binaries are published under GitHub Releases.
- The app verifies SHA-256, package identity, version code, and signing-key continuity before Android installs an update.

Do not publish API keys, databases, signing keys, or private analysis history in this repository.
